1. Quick Start

NEXUS-01 is a zero-build-step, standalone template. You can run it immediately without complex bundlers or build tools:

# Option A: Python local server
python -m http.server 8080
# Option B: Node.js npx serve
npx serve .
# Option C: Double click index.html directly in any modern browser

2. Customization Guide

Changing Brand Colors

The template uses Tailwind CSS with cyan (#38bdf8) and indigo accents. Search for cyan-400 in index.html to replace with your preferred brand color (e.g. emerald, purple, amber).

Tuning the 3D WebGL Galaxy

In index.html around line 760, locate the Three.js particle configuration: 

const particleCount = 2800; // Increase for denser cosmos, decrease for ultra-low-end devices
const color1 = new THREE.Color(0xffffff); // Core stars
const color2 = new THREE.Color(0x38bdf8); // Cyan nebula
const color3 = new THREE.Color(0x818cf8); // Indigo nebula

Tactile Audio Customization

Sound synthesis is 100% procedural via the browser's native Web Audio API (zero audio MP3 files to host or load!). Locate playTapSound() around line 660 to adjust click frequencies or disable sound by setting let isSoundOn = false;.
