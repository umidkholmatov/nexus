- **Live Swarm Orchestration Simulator**: Interactive terminal simulation demonstrating multi-agent task handoff and cryptographic ZK consensus proofs.
- **Interactive Accordion FAQ**: Dynamic protocol Q&A with Lucide micro-animations.

## 🚀 Quick Start

Run instantly without build tools or package managers:

```bash
# Option 1: Python local server
python -m http.server 8080

# Option 2: Node.js npx serve
npx serve .

# Option 3: Double click index.html directly in any modern browser
```
